# dashboards/

This folder holds the **Power BI dashboard file** — the Task 3 deliverable that
has to be built by hand.

## What goes here

```text
Task3_Dashboard.pbix
```

Build it by following [`../POWERBI_GUIDE.md`](../POWERBI_GUIDE.md), then save the
file into this folder (Power BI: **File → Save as**).

## Why it is not already here

Power BI Desktop and Tableau are Windows GUI applications with no command-line
interface, so the `.pbix` / `.twbx` file cannot be generated by a script. The
guide contains every step, the DAX measures to paste, the page layout, and a
table of expected KPI values to verify the result against.

## Reference

- Interactive layout preview: `../reports/html/dashboard_preview.html`
- Static chart reference: `../reports/charts/`
- Full walkthrough notebook: `../notebooks/Task3_Visualization.ipynb`

## Optional alternative

If you prefer not to install the desktop app, build the same dashboard in
**Power BI Service** (app.powerbi.com) in the browser, then
**File → Download this file** to get the `.pbix`, and drop it here.
